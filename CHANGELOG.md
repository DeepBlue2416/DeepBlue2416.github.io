# Changelog

Все значимые изменения проекта «Apple и точка». Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [0.4.0] — 2025-07-28

### Added
- **Редизайн шапки:** логотип «Apple и точка» + селектор города (список из `CONFIG.cities`,
  выбор сохраняется в localStorage), сворачиваемый поиск (кнопка-лупа → оверлей с фокусом и «X»),
  телефон из `CONFIG.contacts.phone`, кнопка «Заказать звонок», иконки Telegram и ВКонтакте,
  счётчики «Избранного» и «Сравнения».
- **Оверлей поиска:** непрозрачный (`bg-white` + `shadow-2xl`, высокий `z-index`), с блокировкой
  прокрутки страницы при открытии.
- **Подсказки пустого поиска:** популярные запросы (iPhone 16 Pro, MacBook M4, AirPods Pro и др.)
  и категории при фокусе на пустом поле.
- **Модалка «Заказать звонок»** (обратный звонок) с маской телефона, согласием 152-ФЗ и Turnstile.
- **Иконки Lucide:** офлайн-набор (`src/js/icons.js`) — все иконки интерфейса переведены на Lucide
  без внешнего CDN (работает и при открытии файла напрямую).
- **Skeleton-загрузчики:** анимированные плейсхолдеры карточек, пока грузится каталог.
- **Маска телефона** `+7 (XXX) XXX-XX-XX` во всех формах с блокировкой отправки при неполном номере.
- **Проверка Turnstile на воркере:** `verifyTurnstile()` в `worker/index.js` (проверка капчи заявок
  через `siteverify`, секрет `TURNSTILE_SECRET`).
- **CHANGELOG.md** и карта проекта (ASCII-дерево) в `README.md`.

### Changed
- **Hero:** новый оффер «Тот самый Apple. Уже в наличии.» с бейджем «Оригинал · Гарантия · Trade-In»
  и блоком из 4 преимуществ (иконки Lucide).
- **Скраббер фото** переведён на Pointer Events (`pointerdown/move/up`) с `touch-action: pan-y` —
  корректная работа на тач-устройствах, вертикальный скролл сохраняется.
- Результаты поиска ведут на страницу товара (раньше открывали форму заявки).

### Fixed
- **Прозрачность выпадающего поиска:** фон сделан на 100% непрозрачным — контент страницы
  больше не просвечивает сквозь результаты.
- Прокрутка страницы блокируется при открытых поиске/модалках и корректно возвращается при закрытии.

## [0.3.0] — 2025-07-27

### Added
- Страница товара `product.html` (галерея, выбор цвета/памяти, характеристики, заявка, Trade-In).
- Hover Image Scrubber в каталоге; Color Swatch Preview на карточках (группировка по модели).
- Speed dial (плавающая кнопка) с выбором способа связи.
- Интеграция Cloudflare Turnstile в форму заявки; реальные `CONFIG` (город Таганрог, apiBase).

### Changed
- Фон интерфейса — off-white (#FAF9F6), карточки — белые.
- Логотип из брендбука (иконка App Store) в `logo-mark.svg`.

## [0.2.0] — 2025-07-26

### Added
- Работа без сервера (file://): classic-скрипты + встроенный каталог `data/products.js`.
- Мобильная адаптация (адаптивная шапка, сетка, модалки).

### Fixed
- Неработавшие кнопки «Избранное»/«Сравнить» (падение инициализации на `fetch` при file://).
- Конфликт объявления `fmt` в разных модулях.

## [0.1.0] — 2025-07-26

### Added
- Первая версия: каталог, умный поиск (транслит/опечатки/раскладка), фильтры, сравнение, избранное,
  Trade-In, две цены, CRM `admin.html`, Cloudflare Worker (Telegram + KV), 152-ФЗ.
