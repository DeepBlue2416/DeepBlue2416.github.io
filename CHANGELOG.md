## [0.28.0] — 2026-08-21 — Fix переключения вариантов на чистых URL + плавная анимация выбора

### Fixed
- **Выбор варианта не работал на боевых чистых URL** `/p/<id>/`: при клике по памяти/SIM
  сбрасывался выбор (например, память откатывалась с «1 ТБ» на «256 ГБ»). Причина: `getId()`
  на пререндер-страницах читает id из **pathname**, а `goVariant()` писал новый id только в
  `?id=` — и render каждый раз перечитывал старый pathname. Теперь адрес меняется по pathname
  (чистый `/p/<новый-id>/`, легаси-хвост `?id=` стирается). Проверено: 256ГБ→1ТБ→2 eSIM
  сохраняет «1 ТБ», URL = `…-1-tb-2-esim-5`, цена и подпись обновляются.
- **Сохранение остальных параметров при выборе** (`bestMatch` вместо `closest`): фиксируем
  только что выбранное измерение, из остальных сохраняем максимум текущего выбора
  (приоритет: цвет > память > SIM). Раньше терялись цвет/память, даже если нужный SKU есть.

### Added
- **Плавная анимация выбора** вместо мгновенной пересборки страницы: переключение варианта
  теперь обновляет карточку «на месте» (in-place) — активные пилюли/свотчи анимируются штатным
  CSS-transition (300 мс), цена меняется коротким fade, галерея при смене цвета — кроссфейдом.
  Нет «скачка» прокрутки и мигания. product.js: модульный `state`, `applyVariant`/`patchInfo`,
  вынесен `wireGallery()`; обработчики выбора/избранного читают `state` (навешиваются один раз).

## [0.24.0] — 2025-08-06 — Обновление пререндера + отзывы через API/CRM

### Added
- **Редактор отзывов в CRM** (`/admin.html` → вкладка «Отзывы»): источники Яндекс/2ГИС,
  рейтинг, число, ссылка, поле «Виджет» и избранные отзывы (автор/дата/оценка/текст) с

  ценами). Включается секретами воркера `GH_DISPATCH_TOKEN` + `GH_REPO`. Плюс ночная
  пересборка по расписанию (deploy.yml `schedule: cron 0 2 * * *`) как страховка.

### Примечание
- Пользователи видят актуальные цены всегда (гидратация из KV); пересборка нужна только
  чтобы статичный HTML пререндера был свежим для поисковых ботов. Подробности — docs/cloudflare-setup.md (Раздел E).

## [0.23.0] — 2025-08-06 — Пререндер карточек для SEO (Google + Яндекс)

### Added
- **Build-time пререндер карточек товаров** (scripts/prerender.js): на сборке генерируются
  статические страницы `dist/p/<id>/index.html` — бот получает готовый HTML (H1, цена, наличие,
  описание, характеристики, JSON-LD Product/Offer/BreadcrumbList, canonical) БЕЗ выполнения JS.
  Пользователю та же страница мгновенно «оживает» (product.js гидратирует #product-root в
  интерактивную карточку). 227 страниц. Чистая генерация на Node — без браузера в CI.
- **Чистые URL** `/p/<id>/`: productLink() отдаёт их на боевом (на file:// — product.html?id=),
  getId() читает id из пути. Легаси `product.html?id=` нормализуется в /p/<id>/ (history.replaceState)
  и его canonical указывает на чистый URL — дублей в индексе нет.
- sitemap.xml переведён на чистые URL /p/<id>/ (228 URL).

### Проверено
- No-JS (бот) рендер: H1/цена/характеристики/JSON-LD видны без JS. Гидратация: селекторы вариантов
  и «Оформить» появляются. Canonical чистый. Легаси ?id нормализуется. Ошибок загрузки ассетов нет.
